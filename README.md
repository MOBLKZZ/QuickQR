# QuickQR

Gerador de QR Code rápido, moderno e funcional desenvolvido para facilitar o compartilhamento de links e textos.

## 🛠️ Especificações do Projeto

| Categoria | Detalhes |
| :--- | :--- |
| **Tecnologias** | HTML5, CSS3, JavaScript (ES6+) |
| **Metodologia** | Mobile-First (Design Responsivo) |
| **Recursos** | Geração instantânea, suporte a PWA |
| **Status** | Concluído 🚀 |
| **Demonstração** | [Clique aqui para testar o projeto](https://moblkzz.github.io/QuickQR/) |

## ⚙️ Como Funciona
1. O usuário digita uma URL ou texto no campo de entrada.
2. O JavaScript processa os dados e renderiza o QR Code em tempo real.
3. O usuário pode salvar ou compartilhar a imagem gerada.
